# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately to the repository owner with a clear description and steps to reproduce it.

We will acknowledge the report, investigate it, and coordinate a fix before public disclosure.

## Key handling

Key Ring is browser-only: submitted keys are held only in memory and sent directly to the provider selected by the user. Do not submit production keys unless you understand and approve that provider request.
